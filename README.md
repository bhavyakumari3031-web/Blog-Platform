# Blog Platform with Comments

Features:
- User registration and login
- Create, edit and delete posts
- Upload images/files
- Display uploaded images/files
- Add comments
- Delete your own comments; post authors can delete comments on their posts
- MongoDB database and REST APIs

## Run backend
1. Open `backend` in terminal.
2. Copy `.env.example` to `.env` and edit values if needed.
3. Run `npm install`
4. Run `npm run dev`

## Run frontend
1. Open `frontend/Blog-Platform` in another terminal.
2. Run `npm install`
3. Run `npm run dev`
4. Open the Vite URL shown in terminal.

MongoDB must be running locally unless you use a MongoDB Atlas connection string.
